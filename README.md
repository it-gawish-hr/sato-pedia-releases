# Sato Pharma · Pedia Line — Android app

**[Download the latest version](https://github.com/it-gawish-hr/sato-pedia-releases/raw/main/Sato-Pedia.apk)**

The Guamusin, Ivyronc and Lacto Advanced detail aid from Sato Pharma. For healthcare professionals only.

**How to install**

1. Open the downloaded file on the phone.
2. If Android asks, allow installs from that app.
3. Tap **Install**.

A new version installs over the old one. Once installed, the app tells you when a new version is ready.

**iPhone, iPad or computer**

**[Open the web version](https://sato-pedia.fly.dev/)**

On iPhone: open the link in Safari, tap **Share**, then **Add to Home Screen**. The app then opens from its own icon and works without internet.
